# 运行截图放置说明

第四章已经预留以下截图位置。将图片按文件名放到本目录后，LaTeX 会自动显示真实截图；没有图片时会显示占位框。

- `portal-register.png`：用户首次注册页，建议截 `/portal/register`。
- `portal-face-challenge.png`：人脸采集动作挑战页，建议截 `/portal/face`。
- `portal-home.png`：用户中心审核状态页，建议截 `/portal/home`。
- `terminal-screen.png`：树莓派本地终端实时识别页，建议截 `/`。
- `terminal-success.png`：终端识别成功并提示签到完成的画面。
- `admin-device-api.png`：管理员设备健康/状态接口运行结果，可截 Windows 管理端、Apifox、Postman 或 FastAPI 文档页。
- `admin-face-review.png`：管理员人脸审核页或审核接口调用结果。
- `admin-attendance.png`：管理员考勤记录查询页或接口调用结果。
